# Power BI Dashboard

The project dashboard tracks campaign ROI and acquisition efficiency.

Recommended dashboard sections:

- KPI cards: Revenue, Ad Spend, Profit, ROAS, Conversion Rate, CPA
- Platform performance
- Retargeting vs non-retargeting conversion performance
- Conversion funnel: Impressions → Clicks → Conversions
- Campaign objective / audience performance
- Trend analysis over time
